# OHM Works ⚡

An interactive circuit editor and visualizer built using **Python** and **Pygame**. OHM Works aims to become a complete Electrical Circuit Design & Analysis Suite capable of creating, editing, analyzing, and simulating electrical circuits.

---

## 🚧 Project Status

This project is under active development.

**Current Version:** `v0.3.0 (Development Build)`

### Current Progress

- ✅ Component Placement
- ✅ Drag & Drop
- ✅ Active Component Selection
- ✅ Component Rotation (90°)
- ✅ Terminal-Based Wiring
- ✅ Dynamic Wire Updates
- ✅ Orthogonal (90°) Wire Routing
- ✅ Multi-Point Wire Bending
- 🚧 Circuit Solver (Coming Soon)

---

# ✨ Features

- Interactive circuit editor
- Component placement
- Drag & Drop support
- Component rotation using **R** key
- Terminal-aware wire connections
- Orthogonal (90°) wire routing
- Multi-point wire bending
- Automatic wire updates when components move
- Interactive drawing canvas
- Modern dark-themed interface

# ⌨️ Controls

| Action | Input |
|---------|------|
| Select Component | Left Click |
| Place Component | Left Click on Canvas |
| Drag Component | Mouse Drag |
| Rotate Selected Component | **R** |
| Start Wire | Click Terminal |
| Add Bend Point | Click Canvas |
| Finish Wire | Click Destination Terminal |

## ⭐ Future Vision

The goal of **OHM Works** is to evolve into a complete Electrical Engineering Design Suite capable of circuit editing, simulation, analysis, visualization, and AI-assisted circuit recognition—bringing together features inspired by tools like Proteus, KiCad, LTspice, and Falstad into a single modern application.
