# OHM Works ⚡

An interactive circuit editor and visualizer built using Python and Pygame.

## 🚧 Project Status

This project is currently under development.

Current Version: v0.1.0

## Features

- Add electrical components
- Drag and move components
- Terminal-based wiring
- Resistor, Battery, Capacitor, and Inductor support
- Interactive canvas

## Upcoming Features

- Move and Connect modes
- Multi-point wires
- KCL and KVL solver
- RL, RC, and RLC circuit analysis
- Circuit image recognition
- Graph visualization

## Technologies Used

- Python
- Pygame

## Installation

```bash
pip install -r requirements.txt
python main.py
```
